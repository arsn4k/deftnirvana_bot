# 🎸💀 Deftones & Nirvana Photo Bot

Telegram бот, який надсилає унікальні фотографії Deftones та Nirvana.
Фото не повторюються, поки всі не будуть показані.

---

## 📁 Структура проєкту

```
deftnirvana_bot/
├── bot.py               ← головний код бота
├── requirements.txt     ← залежності Python
├── Procfile             ← для Railway хостингу
├── .gitignore
├── README.md
└── photos/
    ├── deftones/        ← сюди додаєш фото Deftones
    │   ├── photo1.jpg
    │   └── ...
    └── nirvana/         ← сюди додаєш фото Nirvana
        ├── photo1.jpg
        └── ...
```

---

## 🚀 КРОК 1 — Отримай Telegram токен

1. Відкрий Telegram → знайди `@BotFather`
2. Надішли `/newbot`
3. Введи назву бота, наприклад: `DeftNirvana Photos`
4. Введи username, наприклад: `deftnirvana_photo_bot`
5. Скопіюй токен (виглядає як `7123456789:AAHxyz...`)
6. Відкрий файл `bot.py` та встав токен у рядок:
   ```python
   TOKEN = "ВАШ_ТОКЕН_ТУТ"
   ```

---

## 📸 КРОК 2 — Додай фотографії

Поклади фото у папки:
- `photos/deftones/` — фото Deftones (мінімум 30, краще 60+)
- `photos/nirvana/`  — фото Nirvana  (мінімум 30, краще 60+)

Підтримувані формати: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`

### Де взяти фото:
- `last.fm/music/Deftones/+images` — офіційні фото
- `last.fm/music/Nirvana/+images`
- Google Images → Tools → Розмір: Великий
- Розширення браузера "Image Downloader" для масового збереження

## ☁️ КРОК 3 — Деплой на Railway (безкоштовно, 24/7)

### 3.1 Завантаж код на GitHub
1. Зареєструйся на `github.com`
2. Створи новий репозиторій (назви `deftnirvana-bot`)
3. Завантаж всі файли проєкту (включно з папкою `photos/`)
4. Зроби commit і push

### 3.2 Запусти на Railway
1. Зайди на `railway.app`
2. Увійди через GitHub
3. Натисни **"New Project"** → **"Deploy from GitHub repo"**
4. Обери свій репозиторій `deftnirvana-bot`
5. Railway автоматично знайде `Procfile` і запустить бота
6. Готово! Бот працює 24/7

### 3.3 Перевір що бот живий
- Відкрий свій бот в Telegram
- Напиши `/start`
- Повинні з'явитись кнопки

## ❓ Часті питання

**Чи повторюються фото?**
Ні. Бот запам'ятовує які фото вже показав. Повторення починаються лише після того, як всі фото були показані хоч раз.

**Що якщо додати нові фото під час роботи?**
Бот підхопить їх автоматично — перезапуск не потрібен.

**Чи потрібен телефон весь час увімкнений?**
Ні! Бот працює на сервері Railway. Телефон потрібен лише щоб писати боту в Telegram.

**Скільки коштує Railway?**
Безкоштовний план покриває легкий бот. При потребі — $5/міс.
